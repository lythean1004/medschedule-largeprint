> **확인하고 사용하는 시간표**  
> 약봉투에서 추출한 내용은 초안입니다. 사용자가 원본과 대조하고 필요한 내용을 수정한 뒤 시간표를 만듭니다. 복용 방법을 결정하거나 의료 전문가의 판단을 대신하는 서비스가 아닙니다.


## ✨ 누구를 위한 서비스인가요?

| 사용자 | 필요한 도움 |
| :--- | :--- |
| 작은 글씨가 불편한 분 | 약 이름과 복용 내용을 큰 글씨로 확인 |
| 부모님·가족을 돕는 보호자 | 원본을 보면서 추출 내용을 대조·수정 |
| 확인한 내용을 전달하려는 분 | 시간표 텍스트 공유 또는 종이 출력 |

회원가입과 앱 설치 없이 웹에서 사용합니다. 추출 결과에 따라 보호자의 수정 입력이 필요합니다.

## 📷 사용 순서

| 단계 | 할 일 |
| :---: | :--- |
| **1** | **저장된 사진 선택** 또는 **사진 찍기** |
| **2** | 미리보기에서 방향 확인 → 필요하면 회전·확대 |
| **3** | **이 사진으로 읽기**를 눌러 분석 시작 |
| **4** | 원본과 약 이름·1회량·횟수·유형·시간대를 대조 |
| **5** | 필요한 복용 조건을 입력하고 약별 확인란 체크 |
| **6** | 빠진 약과 문서 확인 사항을 검토하고 전체 확인 |
| **7** | **큰 글씨 시간표 보기** → 카드 탐색·공유·인쇄 |

사진 선택이나 회전만으로 분석 요청을 보내지 않습니다.

## 🗂️ 네 장의 큰글씨 카드

| ☀️ 아침 | 🍽️ 점심 | 🌙 저녁 | 🕒 그 외 |
| :---: | :---: | :---: | :---: |
| 확인한 아침 약 | 확인한 점심 약 | 확인한 저녁 약 | 자기 전·필요시·비매일 약 |

- 약이 없는 시간대에도 빈 상태 안내를 표시합니다.
- 데스크톱에서는 사진과 수정 화면을 나란히 배치하고 사진 영역을 고정합니다.
- 모바일에서는 세로 배치와 결과 카드의 가로 스크롤을 사용합니다.
- 이전·다음과 시간대 바로가기 버튼으로 카드를 탐색합니다.

## 📝 확인과 수정 방식

| 항목 | 현재 동작 |
| :--- | :--- |
| 약 이름·1회량 | 필수값 누락 시 표시하고 확인 차단 |
| 복용 횟수 | 매일 복용 유형에서 필수 검사 |
| 복용 유형 | 매일 / 필요시 / 비매일 중 확인한 유형 선택 |
| 시간대 | 매일 복용 유형은 확인한 시간대 선택 필요 |
| 복용 조건 | **선택 입력**. 회색 예시 `식전/식후 등` 표시 |
| 확인 근거 | 원본 직접 확인이 초기 선택이며, 초기 선택만으로 확인 완료되지 않음 |
| 약별 확인 | 사용자가 직접 체크. 확인 근거를 보호자 확인 상태로 변경 |
| 전체 확인 | 모든 약의 대조 완료 후 사용자가 직접 체크 |

**복용 조건을 비워 두면** 카드·인쇄·공유에 `복용 조건: 별도 입력 없음`으로 표시합니다. 빈칸이나 공백을 ‘조건 없음’ 또는 ‘조건 확인 완료’로 확정하지 않습니다. 실제 입력된 조건은 그대로 보존하며, 회색 예시 문구는 데이터로 저장하지 않습니다.

최종 확인은 필수값을 자동으로 채우지 않습니다. 특히 필요시·비매일 약도 조건을 비워 둘 수 있으므로, 시간표에 생략된 조건은 원본에서 별도로 확인해야 합니다.

내용을 수정하면 관련 약별·전체 확인과 기존 결과가 해제됩니다. 복용 조건·횟수·유형 변경 시 관련 시간대와 확인 근거도 초기화합니다.

## 🔄 사진 처리와 요청 안정화

- 최초 선택과 회전 결과: 긴 변 **최대 2400px**, JPEG 품질 **0.9**
- 작은 이미지는 확대하지 않고, 투명 부분은 흰 배경으로 변환
- 최초 디코딩한 원본을 유지하고 그 원본에서 매번 회전 결과 생성
- 미리보기와 분석 전송에 동일한 변환 데이터 사용
- 읽기·변환·분석 중 중복 조작 제한
- 이전 작업의 늦은 응답이 현재 사진과 상태를 바꾸지 않도록 검사
- 화면 분석 요청은 **90초** 제한, 성공·실패 모두 타이머 정리

해상도 제한이 전송 바이트 크기를 보장하지는 않습니다. 원본 이미지 디코딩에는 여전히 메모리가 필요합니다. 작은 글씨의 선명도, 지원 이미지 형식, 카메라 호출은 실제 사진과 기기에서 확인해야 합니다.

## 📤 공유와 인쇄

| 기능 | 제공 범위 |
| :--- | :--- |
| 공유 | 지원되는 기기의 공유 기능으로 시간표 **텍스트** 전달 |
| 복사 | 클립보드 복사, 실패 시 수동 복사용 텍스트 제공 |
| 인쇄 | 확인된 네 카드를 세로로 펼쳐 출력 |
| PDF | 브라우저·운영체제가 지원하는 인쇄 저장 기능 이용 |

원본 사진·편집란·조작 버튼·공유 미리보기는 인쇄에서 제외합니다. 결과와 인쇄물·공유문에는 원본 대조 및 약사 문의 안내가 포함됩니다.

A4 한 장 출력을 보장하지 않습니다. 약 개수와 인쇄 설정에 따라 여러 장이 될 수 있습니다. 공유 링크 발급·카드 이미지 공유·복약 알림은 현재 범위에 포함되지 않습니다.

## ⚙️ 기술 구성

| 구성 | 역할 |
| :--- | :--- |
| `index.html` | 사진 처리, 초안 편집·확인, 결과 카드·공유·인쇄 |
| `api/schedule.js` | 서버에서 OCR와 구조화 추출 요청 처리 |
| Upstage Document OCR | 약봉투 이미지에서 텍스트 추출 |
| Solar Pro 4 (`solar-pro4`) | 텍스트에서 약별 JSON 초안 추출 |
| Vercel | 정적 화면과 서버리스 함수 배포 |

### API 계약

`POST /api/schedule`

```json
{ "image_b64": "data:image/jpeg;base64,..." }
```

성공: `{ "draft": ... }` · 실패: `{ "error": "..." }`

초안은 `medications`, `document_issues`, `extraction_status`로 구성됩니다. 약별 필드는 `value`, `evidence`, `status`를 사용합니다.

현재 서버 요청 핸들러는 `extractMedicationDraft`를 호출합니다. 파일에 남은 기존 `PROMPT`·`solarSchedule`은 활성 추출 경로가 아닙니다.

### 추출 원칙

- 약명·숫자·소수점·단위를 추측하거나 자동 교정하지 않도록 지시
- 횟수만으로 시간대를 만들지 않도록 지시
- 식전·식후만 있는 경우 시간대를 임의로 배치하지 않도록 지시
- 필요시·비매일 약은 일반 시간대와 구분
- 읽지 못한 것을 원본에 없다고 단정하지 않도록 지시
- 개인정보와 의학적 판단을 결과에 넣지 않도록 지시

서버는 응답 종료 상태, JSON 구조, 필드 상태, 허용 시간대와 중복 항목 등을 검사합니다. 이는 OCR 정확성·의학적 정확성·개인정보 제거를 보장하는 검사가 아닙니다.

## 🚀 실행 및 배포

1. 저장소를 복제하고 의존성을 설치합니다.
2. 서버 환경변수 `SOLAR_PRO_API_KEY`를 설정합니다.
3. Vercel CLI가 준비된 환경에서 로컬 서버를 실행합니다.

```bash
git clone https://github.com/lythean1004/medschedule-largeprint.git
cd medschedule-largeprint
npm install
vercel dev
```

키는 HTML·소스 코드·GitHub에 넣지 마세요. HTML 파일만 직접 열어서는 같은 도메인의 서버 API 연결을 검사할 수 없습니다.

검토본을 적용할 때에는 저장소 최상위 `index.html`을 교체하고, 배포 서비스에서 완료 상태를 확인하세요. README 교체는 화면 코드 배포를 대신하지 않습니다.

### 남은 작은 UI 보완

`index.html`의 복용 조건 회색 설명은 빈 조건과 시간대를 가진 매일 복용 약에서 카드 끝에 표시됩니다. 모든 유형의 조건 입력 바로 아래에 일관되게 안내하는 배치는 후속 보완 대상입니다.

## 🔐 개인정보와 사용 범위

사진과 추출 텍스트는 분석 과정에서 서버 및 외부 API로 전달됩니다. 단말기 안에서만 처리되는 서비스가 아닙니다. 운영 로그와 외부 서비스의 보관 정책은 별도 확인이 필요하며, 무저장이나 완전한 개인정보 제거를 보장하지 않습니다.

공유·인쇄 전에 포함된 정보를 확인해 주세요. 실제 사용자 평가나 복약 오류 감소 효과가 검증됐다는 주장은 하지 않습니다.
