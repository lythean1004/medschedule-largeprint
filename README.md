# 약 먹는 시간표 (medschedule-largeprint)

약봉투 사진을 보호자가 원본과 대조하고 수정한 뒤, 큰 글씨 시간표로 확인·공유·인쇄하는 웹서비스입니다.

- 서비스: https://medschedule-largeprint.vercel.app/
- 저장소: https://github.com/lythean1004/medschedule-largeprint
- 스킬명: `medicine-schedule-largeprint`

> 개발·검증 중인 서비스입니다. 이 문서는 코드 기준 커밋 [7327a3e](https://github.com/lythean1004/medschedule-largeprint/commit/7327a3e7e32d54c9b5451c6b23bc054c58f9f849)을 확인해 작성했습니다. 실제 운영 배포와 기기별 동작까지 검증 완료된 것은 아닙니다.

## 누구를 위한 서비스인가요?

- 작은 약봉투 글씨를 읽기 어려운 분
- 부모님이나 가족의 약봉투 정리를 돕는 보호자
- 확인한 복용 내용을 큰 글씨나 종이로 전달하려는 분

회원가입·앱 설치 없이 웹에서 사용할 수 있습니다. 추출 내용에 따라 보호자의 수정 입력이 필요합니다.

## 사용 방법

1. 저장된 사진을 선택하거나 **사진 찍기**를 누릅니다.
2. 미리보기에서 사진 방향과 선명도를 확인합니다.
3. 필요하면 좌우 회전 버튼으로 방향을 조정합니다.
4. **이 사진으로 읽기**를 눌러 분석을 시작합니다.
5. 원본과 약별 정보를 대조하고 필요한 내용을 수정합니다.
6. 복용 유형·시간대·확인 근거를 확인하고 약별 확인란을 체크합니다.
7. 원본의 약 목록과 문서 확인 사항을 살핀 뒤 전체 확인란을 체크합니다.
8. **큰 글씨 시간표 보기**를 누릅니다.
9. 필요하면 텍스트를 공유·복사하거나 시간표를 인쇄합니다.

사진 선택만으로 분석 요청이 실행되지는 않습니다.

## 주요 기능

### 사진 확인과 회전

- 저장된 사진 선택 및 모바일 카메라 사용 요청
- 촬영 안내, 원본 미리보기, 확대·축소
- 좌우 90도 회전
- 최초 디코딩한 원본을 기준으로 회전하여 중복 회전 방지
- 회전 결과를 미리보기와 분석 요청에 동일하게 사용
- 사진 읽기·분석·회전 중 중복 조작 제한
- 오래된 비동기 응답이 현재 화면을 변경하지 않도록 작업 번호 검사

카메라와 이미지 형식 지원은 기기·브라우저에 따라 다릅니다. 회전 상태 안내의 화면 연결은 아직 보완 대상입니다.

### 보호자 대조·수정

다음 내용을 확인하고 수정할 수 있습니다.

- 약 이름
- 1회 먹는 양
- 복용 횟수
- 복용 시점·조건
- 며칠분
- 복용 유형: 매일 / 필요시 / 비매일 / 확인 필요
- 시간대 및 복용 시점·시간대 확인 근거

확인 근거의 초기 선택은 원본 직접 확인입니다. 초기 선택만으로 보호자 확인 완료가 되지는 않습니다.

약별 확인란을 체크하면 확인 근거를 보호자가 확인한 상태로 변경합니다. 필수값 누락을 자동으로 채우지는 않습니다.

내용을 수정하면 약별·전체 확인과 기존 확정 결과를 무효화합니다. 복용 시점이나 횟수를 수정하면 시간대와 확인 근거도 초기화합니다.

### 큰 글씨 결과와 모바일 화면

확인한 결과를 **아침·점심·저녁·그 외** 네 카드로 표시합니다. 그 외 카드에는 자기 전·필요시·비매일 복용 항목 등을 구분합니다.

- 데스크톱: 원본 사진과 수정 화면을 나란히 배치
- 모바일: 세로 배치와 결과 카드 가로 탐색
- 긴 약 이름의 줄바꿈, 큰 입력 요소와 확인란
- 손가락 스크롤에 따른 현재 카드 표시 갱신

### 공유·복사·인쇄

- 지원되는 환경에서 기기의 공유 기능 사용
- 시간표 텍스트 복사
- 자동 복사가 어려울 때 수동 복사용 텍스트 제공
- 확인된 결과에 대한 인쇄 전 상태 검사
- 인쇄 시 전체 결과 카드를 세로로 배치
- 원본 사진과 수정·조작 영역은 인쇄에서 제외

현재 공유는 텍스트 방식입니다. 카드 이미지 생성과 공유 링크 발급은 포함하지 않습니다.

출력 페이지 수는 약 개수·내용과 인쇄 설정에 따라 달라지며, A4 한 장 출력을 보장하지 않습니다.

## 추출·확인 원칙

현재 서버의 구조화 추출 프롬프트는 다음 원칙을 지시합니다.

- 약 이름·숫자·소수점·단위를 추측하거나 자동 교정하지 않기
- 복용 횟수만으로 아침·점심·저녁을 지정하지 않기
- 식전·식후만 있을 때 특정 시간대로 바꾸지 않기
- 읽지 못한 내용을 원본에 없는 것으로 단정하지 않기
- 필요시·비매일 약을 일반 시간대에 자동 배치하지 않기
- 확인된 필드에는 짧은 OCR 근거를 남기고, 미확인은 별도 상태로 표시
- 개인정보를 추출 결과에 포함하지 않기
- 효능·부작용·병용 판단·복용 변경·종료일 계산을 하지 않기

서버는 JSON 구조, 필드 상태, 허용 시간대, 중복 ID·시간대, 응답 종료 상태 등을 검사합니다. 프롬프트와 구조 검사는 OCR·모델 결과의 정확성이나 개인정보 제거를 보장하지 않습니다.

불명확한 내용은 원본 또는 약사에게 확인해야 합니다. 이 서비스는 복용 방법을 새로 결정하지 않으며, 보호자 확인은 의료 전문가의 검토를 대신하지 않습니다.

## 기술 구성과 데이터 흐름

| 구성 | 역할 |
| --- | --- |
| `index.html` | 사진 확인·회전, 약별 수정·확인, 결과 카드·공유·인쇄 |
| `api/schedule.js` | Vercel 서버리스 요청 처리 |
| Upstage Document OCR | 이미지에서 문자 추출 |
| Solar Pro 4 (`solar-pro4`) | OCR 텍스트에서 약별 구조화 초안 추출 |
| Vercel | 웹서비스 배포 |

처리 흐름:

사진 확인·회전 → `/api/schedule` → OCR → Solar 구조화 추출·검사 → `{ draft }` 반환 → 보호자 대조·수정 → 확정 시간표

요청은 POST이며 다음 필드를 사용합니다.

```json
{
  "image_b64": "이미지 데이터"
}
```

성공 응답은 `{ "draft": ... }` 형태이며, 초안에는 `medications`, `document_issues`, `extraction_status`가 포함됩니다. 오류는 `{ "error": "..." }`로 반환합니다.

현재 요청 핸들러는 `extractMedicationDraft`를 사용합니다. 파일에 남아 있는 기존 `PROMPT`와 `solarSchedule`은 현재 핸들러의 추출 경로가 아닙니다.

## 환경변수

`SOLAR_PRO_API_KEY`

서버의 Upstage OCR·Solar 호출에 사용합니다. 키는 Vercel 환경변수에 등록하고 코드·HTML·GitHub에 포함하지 마세요.

## 로컬 실행

Node.js와 Vercel CLI가 준비된 환경에서:

```bash
git clone https://github.com/lythean1004/medschedule-largeprint.git
cd medschedule-largeprint
npm install
vercel dev
```

로컬 API 실행에도 `SOLAR_PRO_API_KEY` 설정이 필요합니다. 키가 포함된 환경 파일은 커밋하지 마세요. HTML만 직접 열어서는 서버 API 연결을 검사할 수 없습니다.

## 검증 상태

현재 화면 코드와 동일한 검토본을 대상으로, 가짜 데이터·지연 응답을 사용해 확인한 항목입니다.

- 자바스크립트 문법
- 정상 분석 응답의 초안 표시와 실패 응답 처리
- 가짜 이미지 변환을 통한 회전 각도 변경과 원본 재사용
- 변환 실패 시 상태 유지 및 잠금 해제
- 분석·회전 연속 호출 제한
- 오래된 응답의 화면 변경 차단
- 오래된 작업이 새 작업의 잠금을 해제하지 않는지

위 검사는 실제 사진·휴대폰·서버 연결을 포함한 전체 서비스 검증이 아닙니다. 저장소에 자동화 테스트 모음이 포함돼 있다는 의미도 아닙니다.

## 시연·사용성 확인

1. 정상 사진으로 업로드부터 보호자 확인·시간표 표시까지 진행합니다.
2. 일부가 불명확한 사진에서 확인 필요 항목을 처리합니다.
3. 사진 회전 후 다시 분석하고, 이전 결과가 남지 않는지 확인합니다.
4. 모바일 카드 탐색·공유·인쇄를 확인합니다.

사용성 평가는 완료 시간, 수정 항목 수, 미확인 항목 인지 여부, 도움 없이 완료했는지 등을 실제 관찰해 기록할 수 있습니다. 사용자 평가나 복약 오류 감소 효과가 검증됐다고 주장하지 않습니다.

## 개인정보

사진과 추출 내용은 분석 과정에서 서버 및 외부 API로 전달됩니다. 단말기 안에서만 처리되는 서비스는 아닙니다.

데이터 보관·로그 정책은 운영 서버와 외부 API 설정을 확인해야 합니다. 무저장 또는 완전한 개인정보 제거를 보장하지 않습니다. 공유·인쇄 전에 내용과 개인정보 포함 여부를 확인해 주세요.
